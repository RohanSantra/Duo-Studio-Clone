# 🎨 Duo Studio – Creative Agency Website Clone

This is a modern, fully responsive **clone** of the Duo Studio website, built using **HTML**, **CSS**, and **JavaScript**, with animation support via **GSAP** and **Locomotive Scroll**.

## 📸 Project Overview

This website clone replicates the digital aesthetics and interactions of [Duo Studio](https://duo-studio.co/), a creative agency based in Washington DC. It features:

- Smooth scrolling & parallax effects using **Locomotive Scroll**
- Seamless animations triggered by scroll using **GSAP + ScrollTrigger**
- Video integration and animated hero section
- Responsive design for all devices
- Custom cursor and interactive navigation
- Modern UI/UX with clean, bold typography using **PP Mori**

---

## 🛠️ Technologies & Assets Used

| Category             | Tools/Assets                                 |
|----------------------|----------------------------------------------|
| **HTML5 / CSS3**     | Semantic structure and layout styling        |
| **JavaScript (ES6)** | DOM manipulation and interactivity           |
| **GSAP**             | Animation handling and scroll triggers       |
| **ScrollTrigger**    | Advanced scroll-based animations             |
| **Locomotive Scroll**| Smooth scrolling and scroll behavior         |
| **Typography**       | `PP Mori` (via `ppmori.ttf`, `ppmori-regular.woff2`) |
| **Media**            | Web-optimized videos, images (WebP format)   |
